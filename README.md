Para separarnos los trabajos:
1º Primero hacemos un git branch
2º Para publicar la rama en la que estáis git push -u origin develop
3º Para cambiar de ramas se hace: git switch develop | git pull origin develop | git switch -c feature/carrito
4º Para añadir la rama hacemos: git add . | git commit -m "Añade carrito de compra" | git push -u origin feature/carrito
5º Una vez integrada la rama anterio de carrito(es un ejemplo) vamos a subir la de dvelop para que se quefden los cambios y los demás puedan verlo: git switch develop | git pull origin develop
